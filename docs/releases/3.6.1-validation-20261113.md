# 3.6.1 Release Validation - 13 November 2026

Version 3.6.1, build 20261113180633. The owner explicitly approved stable ad-hoc
distribution, including lack of Developer ID/notarization, possible macOS
security warnings and renewed privacy grants. Standard signing guards are not
weakened; packaging requires an explicit stable ad-hoc approval flag.

The candidate includes the main maintenance closeout, Settings appearance fix,
connection diagnostics and independent-queue heartbeat (4fbdbd5).
No old rc.2 archive is reused. SHA256SUMS and package-manifest.json identify
the four rebuilt archives and their exact source commit.

## Candidate Results

- Fresh Sender Release build is universal arm64/x86_64. Both thin app archives
  carry 3.6.1 / 20261113180633 and macOS 14.0 minimum requirements.
- Fresh Receiver builds/package assembly succeed natively on both Macs.
  Bundled dependency requirements are macOS 15.0 on ARM and 14.0 on Intel.
- All 212 isolated CLI Sender XCTest cases pass against these release sources
  and bundle metadata. This is not an application-hosted XCTest run.
- Each native Receiver passes 697 portable checks plus parser-yield and logging
  regressions. Seven negative Sender signing/update guard checks pass.
- All four archives pass ZIP integrity, extraction, exact version/build and
  architecture checks, strict deep signature validation and resource checks.
  Executable/dylib dependency inspection finds no external Homebrew references.
- Each app/architecture passes two bounded native --permission-status probes;
  these exit without normal UI startup or permission requests. Persistent-signing
  and real privacy-grant migration remain untested, not certified.
- SHA256SUMS and the manifest are generated from the verified archive bytes.
  The final verification is rerun after the source commit is fixed, before upload.
- The installed Sender PID 16154 and Receiver PID 79070 remain unchanged.

## Acceptance Limits

The isolated follow-up passed 212 Sender tests and reproduced/resolved timer
starvation with an independent Receiver watchdog. This does not establish the
cause of every real intermittent disconnect. The user requested isolated tests
only; installed apps, active sessions, settings and privacy grants are untouched.
Physical reconnect, sleep/wake, cable interruption, capture, long stress, audible
audio and exact input/cursor behavior have not received fresh acceptance.
Native C tests/builds do not substitute for real two-Mac GUI acceptance.

GitHub Actions remains disabled. Local results must not be described as hosted CI.
The previous staging and investigation documents are historical records, not
evidence of signed/notarized distribution or a universal disconnect fix.
