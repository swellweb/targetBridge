# TargetBridge 3.5.1

A maintenance update to 3.5.0, developed on `maint-3.5` without changing `main`.
Update both Sender and Receiver for the complete set of fixes.

## Display and input

- Preserve keyboard and mouse release events when the Receiver input queue is under pressure.
- Preserve native macOS cursor shapes by default, including the screenshot crosshair. The custom overlay is used only when the large-cursor option is enabled.
- Report the physical Receiver panel geometry and preserve native 5K dimensions when the desktop is scaled with HiDPI.
- Fall back to software decoding when VideoToolbox cannot decode a stream on older hardware. Performance depends on the Mac and stream profile.

## Receiver lifecycle

- Allow display sleep while waiting for a Sender, including before the first connection (#171).
- Open audio output only when an audio frame arrives and close it when the session ends, avoiding an idle audio device that prevents sleep (#172).
- Guard the idle watchdog against clock underflow (#173).
- Keep local notification banners behind the active monitor surface during fullscreen and display transitions (#186). Repeated activation preserves pending retries; teardown removes observers and invalidates stale retries.

This release does not change the active-session display-sleep policy. The separate active-session sleep proposal is not included.

## Packaging and validation

- Package SDL runtimes and their dependencies safely (#189, incorporating #181 and #188).
- Support explicit version/build overrides and configurable Sender build configuration (#180).
- Add a documented AppKit monitor-shield lifecycle test: [Testing](../Testing.md#6-monitor-shield-lifecycle-macos-gui-session).
- Keep existing shared translations validated for English, Italian, German, French, and Chinese.

The integration passed Sender and Receiver CI on Apple Silicon and Intel, 111 local Sender unit tests, and 654 Receiver checks on each architecture. Monitor-shield lifecycle tests passed on both Macs. A real Thunderbolt 5K session, stop/reconnect, idle resource release, watchdog timeout and malformed/partial-packet recovery were tested. The maintainer also reported that the installed test build appeared to work correctly in normal use. These checks are not a guarantee of constant FPS or compatibility with every Mac.

## Downloads and upgrade

- `TargetBridge-arm64.app.zip`: Sender for Apple Silicon.
- `TargetBridge-x86_64.app.zip`: Sender for Intel.
- `TargetBridge-Receiver-arm64.app.zip`: Receiver for Apple Silicon.
- `TargetBridge-Receiver-x86_64.app.zip`: Receiver for Intel.

Sender requires macOS 14 or later; Receiver requires macOS 11 or later. Replace the existing app in Applications rather than keeping multiple copies. If macOS no longer recognizes a permission after the update, re-enable it for that installed copy and reopen the app. Screen Recording is needed on the Sender; Input Dockstation permissions must be checked on both Macs according to their roles. See [Input Dockstation](../Features.md#input-dockstation).
