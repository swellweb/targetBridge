# TargetBridge 3.6.1

Release preparation based on the validated maintenance sources on main,
including the Settings appearance correction merged on 12 November.
These notes do not indicate that the release or new downloads are published.

## Downloads And Requirements

| App | Apple Silicon | Intel |
| --- | --- | --- |
| Sender | macOS 14+ | macOS 14+ |
| Receiver | macOS 15+ | macOS 14+ |

The Receiver requirements reflect the actual bundled dependencies.
Ventura and Big Sur are not supported by these packages.

## Changes

- Chinese wording and first-launch system-language selection (#212, #213).
- Translated connecting screen, corrected idle dashboard orientation and
  small-window layout (#214, #215).
- Exclude development scripts from the Sender app bundle (#216).
- Align footer and bundle build identifiers (#217, #219).
- Restore Full HD labels and complete Italian UI translations (#220).
- Preserve active status when the first frame arrives early (#222).
- Persist and correctly apply the menu-bar icon preference (#224).
- Present the newest decoded frame under backlog; cooperatively yield between
  packets without dropping encoded data, and respect teardown (#230).
- Space keyframes and cap peak rate for the existing experimental 5K60
  profile (#231). Sustained 5K60 is not guaranteed.
- Advertise hardware and software HEVC decoding separately; require explicit
  software support and safely handle key-only Bonjour TXT entries (#232).
- Make Settings readable in both system appearances, preserving the existing
  dark dashboard and About window (#235, appearance-only commit from #208).
- Keep heartbeat delivery active during menu tracking and modal panels; retain
  lifecycle diagnostics when the Receiver's stderr is not captured. See the
  [disconnect investigation](3.6.1-disconnect-investigation-20261112.md).

## Safety And Known Limits

Existing 3.6.1-rc.2 downloads are ad-hoc signed development builds; they do not
contain the Settings appearance correction. They are not renamed or reused as
the 3.6.1 stable downloads. Stable signing guards remain enabled; a distributable
3.6.1 package still requires the configured release identity and acceptance.

No #221 window-lifecycle change, Retina 16:10, RGB10, DPCM, 4.0 changes, new
audio controls, native Metal renderer or sign-in screen mode is included.
The full #221 GUI fixture remains inconclusive; that PR is not marked resolved.

Sleep/wake, physical cable interruption, long stress, audible audio, exact
input/cursor behavior and software-only HEVC throughput are not certified.
The parser budget is cooperative; one decoder callback can exceed 8 ms.
The additional short restart/reconnect check remains inconclusive. This is
not a certified fix for headless, sleep or reconnect problems.
