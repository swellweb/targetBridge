# TargetBridge 3.5.2

A focused maintenance update to 3.5.1, developed on `maint-3.5` without
changing `main`. Update both Sender and Receiver so the installed applications
remain on the same version.

## Input Dockstation

- Fix Shift-click range selection and Command-click non-contiguous selection
  when the Receiver keyboard is the input master and the mouse or trackpad is
  used locally on the Sender.
- Preserve the receiver-held modifier state only for local pointer clicks and
  drags while Receiver Master is active. Releasing the modifier, stopping the
  session, changing role, or switching target removes that state immediately.
- Keep relayed pointer events independent, so their original modifier snapshot
  is not rewritten by the local-pointer compatibility path.
- Exclude Fn, Caps Lock and unrelated keyboard, pointer-motion, and scroll
  events from the compatibility path, preventing stale modifier shortcuts.

## Included maintenance fixes

- Reserve video queue capacity before encoding reference frames, helping avoid
  pressure-induced stalls.
- Distinguish an idle capture from a stalled pipeline, reducing false watchdog
  disconnects when the desktop is static.
- Expose read-only permission probes for Sender and Receiver diagnostics.

## Validation

The release branch passed Sender and Receiver CI on Apple Silicon and Intel.
The Sender completed 140 unit tests, including coverage for remote Shift and
Command applied to local pointer events. The maintainer verified a real
Thunderbolt session and multi-file selection using the Receiver keyboard with
the Sender mouse. This does not guarantee compatibility with every Mac,
application, or input device.

## Downloads and upgrade

- `TargetBridge-arm64.app.zip`: Sender for Apple Silicon.
- `TargetBridge-x86_64.app.zip`: Sender for Intel.
- `TargetBridge-Receiver-arm64.app.zip`: Receiver for Apple Silicon.
- `TargetBridge-Receiver-x86_64.app.zip`: Receiver for Intel.

Sender requires macOS 14 or later; Receiver requires macOS 11 or later. Replace
the existing app in Applications rather than keeping multiple copies. A rebuilt
app may need Screen Recording or Input Dockstation permissions re-enabled for
that installed copy. See [Input Dockstation](../Features.md#input-dockstation).
